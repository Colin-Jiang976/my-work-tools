===========================================================
               AMISDB 一键归档工具 v1.1
===========================================================

【工具简介】
这是一个用于自动化整理每天下载的 AMISDB 工作文件的轻量小工具。
它可以帮我们自动完成以下操作：
1. 扫描下载文件夹（Downloads）中最近下载的 4 个文件。
2. 自动剔除因重复下载产生的重名尾巴（如 " (1)"、"_1" 等）。
3. 自动在桌面创建当天日期的文件夹，并将文件分类移入 AP 和 RDS 目录。
4. 自动打开这 4 个文件供人工 check
5. 自动将当天生成的本地文件夹备份到你个人的网络共享文件夹中。

-----------------------------------------------------------
【首次使用配置方法】（仅需配置一次）
-----------------------------------------------------------
1. 右键点击【archive_files.ps1】文件，选择“编辑”（或用记事本打开）。
2. 在文件最顶部，找到如下代码：
   # 你的本地文件夹路径
   $archivePath  = "……"
   # 你的网络文件夹路径
   $networkPath  = "……" 
3. 将双引号内的路径，修改为你自己在 本地和Network 上实际使用的个人文件夹路径。
4. 保存并关闭文件。

-----------------------------------------------------------
【日常使用说明】
-----------------------------------------------------------
1. ⚠️【核心注意】：请严格按照【先下载2个AP文件，后下载2个RDS文件】的顺序在浏览器中下载！
   （因为脚本是根据下载时间先后，把前2个丢进AP，后2个丢进RDS。如果顺序乱了，分类就会出错）
2. 双击运行文件夹中的【AMISDB.run.bat】。

-----------------------------------------------------------
【注意事项】
1. ⚠️ 下载顺序至关重要！万一不小心先下载了RDS，请不要运行脚本。先把Downloads里的测试文件清空，按【先AP、后RDS】的顺序重新下载一遍再运行。
2. 本工具由于在日语系统下做了中文编码兼容优化，请勿随意更改 [run.bat] 和 [archive_files.ps1] 的文件名和文本编码。
3. 运行工具前，请确保你的电脑已经连接了公司网络/VPN，否则网络备份会提示失败（但本地桌面依然会正常保存）。
4. 默认扫描 Downloads 文件夹中“20分钟内”修改过的文件，若下载完成后放置过久再运行，可能会因为找不到文件而拦截。
