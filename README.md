## 当前展示版的来历

- MonitorTool延续此前已整理并由本人完成本地测试的版本：配置校验、明确的错误处理、可固定时间/本地根目录/预览的入口、虚构日志演示和测试。后续只补HTTP(S)监视网址校验，并未从零重写。
- RdsLogArchive是在原归档工具基础上整理的版本：四文件分组、默认预览、复制保留源文件、拒绝覆盖、哈希校验及命中项按需打开，另有虚构演示和失败处理检查。
- 这批改动此前只保存在项目本地，尚未推送。当前求职展示入口指向上方review/，仓库原有目录用于保留旧版及对照，不把旧版当作本次整理后的版本。

## 示例运行

Windows PowerShell 5.1中进入对应审阅版目录，运行 Run-Demo.cmd。示例使用虚构文件，不扫描真实Downloads，不连接AWS/公司共享目录，不打开真实日志应用。归档演示默认预览；加 -Apply 才在独立演示目录复制虚构文件，保留源文件。配置应根据实际环境另行准备。

## 验证边界

- MonitorTool集中处理日志/页面的准备；登录、日志解释、节假日补查仍由人完成。
- 归档工具不从AWS下载；关键词命中只是提示，ERROR=0也可能命中，不等于事故。
- 审阅版的复制校验、拒绝覆盖、失败保留结果等已有本地验证，不据此宣称现场可用、固定节时或减少漏查。
- 代码与本地测试结果和个人理解程度、独立实现能力分别说明。
